# Telegram Disappearing Media Saver

Этот скрипт на Python позволяет сохранять исчезающие медиафайлы (self-destructing media) из чатов Telegram
с использованием библиотеки [Telethon](https://github.com/LonamiWebs/Telethon).

## 📌 Возможности
- Сохраняет фото, видео и документы из чатов Telegram
- Поддержка самоуничтожающихся сообщений (TTL)
- Возможность указать конкретный чат или сохранять медиа из всех чатов
- Логирование всех действий

## 🚀 Установка

1. Клонируйте или скачайте этот репозиторий
2. Установите зависимости:
```bash
pip install telethon
```
3. Получите **API ID** и **API Hash** на [my.telegram.org](https://my.telegram.org/)

## ⚙️ Настройка

В файле `telegram_disappearing_media_saver.py` заполните:
```python
API_ID = ВАШ_API_ID
API_HASH = 'ВАШ_API_HASH'
PHONE_NUMBER = '+ВАШ_НОМЕР'
SAVE_FOLDER = 'saved_media'  # Папка для сохранения
TARGET_CHAT = None  # None - для всех чатов, или укажите ID/username чата
```

## ▶️ Запуск
```bash
python telegram_disappearing_media_saver.py
```

При первом запуске потребуется ввести код авторизации из Telegram.

## 📂 Сохранение файлов
Все медиа сохраняются в папку, указанную в переменной `SAVE_FOLDER`, с именами формата:
```
ГГГГММДД_ЧЧММСС_НазваниеЧата_Отправитель.расширение
```

## 🛡️ Примечания
- Используйте этот скрипт только в личных целях и в рамках закона вашей страны
- Не используйте для несанкционированного доступа к личной информации
